# 智慧警务数字人安卓APP需求文档（本地视频优化版）

# 一、文档前言

## 1.1 文档目的

明确“智慧警务数字人安卓APP”的核心需求、功能模块、技术实现逻辑，重点优化数字人视频生成方案——采用本地预置“假视频”（非实时生成）替代在线视频流，简化开发流程、降低安卓端性能占用，同时保证警用专业度和用户体验，为项目落地提供清晰的需求依据和执行标准。

## 1.2 核心优化说明

核心调整：放弃扣子空间/第三方实时数字人视频生成，改用**本地预置假视频**（提前制作好的警察数字人视频片段），通过逻辑关联实现“语音问答+本地视频同步播报”，减少API调用、降低性能消耗，简化开发流程，适配中低端安卓设备，同时保留数字人视觉呈现效果和警用专业应答能力。

## 1.3 适用范围

本需求文档适用于项目开发、测试、交付全流程，覆盖扣子空间配置、本地视频制作、安卓APP封装、功能测试等所有环节，供开发人员、测试人员、产品人员及相关协作方参考。

# 二、项目核心定位

## 2.1 产品名称

智慧警务数字人助手（安卓版）

## 2.2 核心定位

基于扣子空间AI能力，结合本地预置数字人假视频、语音唤醒、语音问答技术，打造轻量、流畅、专业的警用咨询类安卓APP，聚焦普法宣传、警务流程答疑、户籍/交通/反诈等政务咨询场景，无需实时生成视频，降低性能占用，适配各类安卓终端。

## 2.3 核心功能（优化后）

- 语音唤醒：支持自定义警用相关唤醒词，快速激活APP，适配安静/嘈杂环境，支持连续对话。

- 语音问答：用户语音提问（普通话），系统实时转文字，通过扣子空间警用知识库+大模型给出专业应答，应答内容同步转为语音输出。

- 本地假视频播报：提前制作警察数字人视频片段（假视频，非实时生成），根据问答场景匹配对应视频，实现“语音应答+视频口型/动作同步”，无实时渲染，降低性能消耗。

- 轻量适配：优化本地视频加载逻辑，适配安卓手机/平板，避免卡顿、闪退，减少内存占用。

- 合规提示：内置紧急警情引导、AI数字人标注，明确不替代真实警务，遵守警用合规要求。

## 2.4 适用场景

政务大厅咨询辅助、社区普法宣传、校园安全宣讲、居民警务问题答疑（户籍办理、身份证补办、违章处理、反诈提醒等），无需联网也可实现基础视频播报（提前缓存视频）。

## 2.5 目标用户

普通居民、企业办事人员、社区工作人员、校园安保人员，核心需求是快速获取专业警务咨询，直观看到数字人播报效果，同时要求APP流畅不卡顿。

# 三、技术架构（优化后，简化流程、降低性能占用）

## 3.1 核心技术栈

|技术模块|核心技术/工具|优化说明（本地视频相关）|
|---|---|---|
|AI核心|扣子空间（知识库、工作流、大模型）|无需配置数字人实时生成插件，仅保留语音转文字、问答、文字转语音能力，简化工作流。|
|语音能力|扣子内置ASR（语音转文字）、TTS（文字转语音）、VAD（语音唤醒）|优先使用扣子内置能力，减少第三方API调用，降低性能消耗，保证语音识别/合成准确率。|
|数字人视频|本地预置假视频（提前制作）、安卓视频播放器|放弃实时生成，采用本地视频缓存，通过场景匹配逻辑调用视频，避免实时渲染占用内存。|
|安卓端|Web封装（优先）/原生安卓WebView|简化封装流程，重点优化本地视频加载速度，适配不同安卓版本和屏幕尺寸。|
## 3.2 核心逻辑流程（优化后，简化版）

核心逻辑：**本地视频预置 → 语音唤醒 → 语音提问 → ASR转文字 → 扣子知识库检索+大模型应答 → TTS转语音 → 匹配本地假视频 → 同步播放视频+语音**

流程说明：无需调用数字人实时生成接口，减少网络请求和性能占用，所有视频提前预置在APP本地，根据用户提问场景自动匹配对应视频片段，实现“语音+视频”同步播报，流程更简洁、运行更流畅。

# 四、详细功能需求（重点完善本地视频相关）

## 4.1 语音唤醒功能

- 唤醒词：支持2组核心唤醒词（可配置），默认“小警”“警务助手”，支持用户自定义（需符合警用规范）。

- 唤醒灵敏度：可调节（默认中高），适配安卓端不同环境（安静/嘈杂），避免误唤醒、漏唤醒。

- 交互反馈：唤醒成功后，本地视频自动播放“唤醒应答片段”（如：“我在，请提问”），同时语音同步输出，视觉+听觉双重反馈。

- 连续对话：支持打断式对话，用户可随时打断视频/语音，继续提问，无需重新唤醒。

## 4.2 语音问答功能

- 语音输入：支持普通话语音提问，识别准确率≥95%，支持轻微口音（如方言式普通话），可识别短句、长句（最长30秒）。

- 转文字：实时将用户语音转为文字，显示在APP界面（可选隐藏），方便用户确认提问内容。

- 专业应答：基于扣子空间警用知识库，大模型给出严谨、官方、专业的回答，严格遵循法律法规和公安官方政策，不提供非官方建议，不处理紧急警情（引导拨打110）。

- 语音输出：将应答文字转为标准普通话语音（警用正式音色），语速适中（可调节），清晰易懂，与本地视频口型、动作同步。

## 4.3 本地假视频相关功能（核心优化点）

### 4.3.1 视频制作要求（假视频标准）

- 形象要求：警察数字人形象（虚拟/真人授权均可），着装规范（警服、警帽），形象庄重、正式，符合警用形象规范，禁止夸张动作、表情。

- 内容要求：
        

    - 基础片段：唤醒应答（如“我在，请提问”“请说出您的问题”）、结束应答（如“感谢咨询，再见”），每个片段时长3-5秒。

    - 场景片段：按警务场景分类制作，覆盖户籍办理、身份证补办、交通法规、反诈宣传、报警流程等核心场景，每个场景对应1-3个视频片段（时长5-15秒），口型贴合常用应答话术（如“身份证丢失可携带户口本到户籍所在地派出所补办”）。

    - 格式要求：MP4格式，分辨率720P（适配安卓终端，兼顾清晰度和内存），帧率24fps，音频同步（与后续TTS语音音色、语速匹配），无水印、无杂音。

- 数量要求：基础片段≥3个，核心场景片段≥20个，可根据后续需求补充新增场景视频。

### 4.3.2 视频预置与加载

- 本地预置：所有视频提前打包至APP安装包，安装后自动缓存至安卓设备本地，无需联网下载，减少网络依赖和加载延迟。

- 加载速度：视频加载时间≤1秒，无卡顿、无黑屏，适配中低端安卓设备（内存≥2GB，安卓版本≥8.0）。

- 缓存管理：支持手动清理视频缓存（可选），避免占用过多设备内存，清理后不影响核心功能使用（视频可重新从安装包提取）。

### 4.3.3 视频匹配逻辑（核心流程）

实现“提问场景→应答内容→本地视频”精准匹配，简化逻辑、提升响应速度，具体流程：

1. 用户语音提问，ASR转为文字，扣子大模型识别提问场景（如“身份证补办”“反诈咨询”）。

2. 大模型生成专业应答文字，同时输出场景标签（如“户籍-身份证补办”）。

3. APP根据场景标签，自动匹配本地对应场景的视频片段（优先匹配与应答话术口型最贴合的片段）。

4. 同步启动视频播放和TTS语音输出，保证视频口型、动作与语音完全同步，避免错位。

5. 若无对应场景视频，自动播放通用视频片段（如数字人正面播报画面），不影响语音应答功能。

### 4.3.4 视频交互控制

- 播放控制：支持暂停、继续播放，视频播放完成后自动停止，回到待机状态（显示数字人静态画面）。

- 画面设置：支持全屏播放、缩放适配，适配不同安卓设备屏幕尺寸，避免画面拉伸、变形。

- 同步控制：语音与视频严格同步，若语音播放速度调整，视频播放速度同步调整（不改变画面比例）。

## 4.4 安卓APP基础功能

- 界面设计：警务蓝为主色调，简洁大气，核心区域显示数字人视频画面，下方显示提问文字/应答文字，底部设置唤醒按钮、音量调节按钮。

- 权限管理：仅申请麦克风、存储（用于视频缓存）权限，不收集用户隐私（不存储语音、位置、身份证等信息）。

- 离线可用：无网络情况下，可唤醒APP、播放本地视频、使用基础问答（提前缓存常用问答内容），联网后同步更新知识库。

- 版本更新：支持手动检查更新，更新包体积控制在100MB以内（避免过大影响安装）。

## 4.5 合规功能

- 紧急引导：当用户提问涉及紧急警情（如“有人抢劫”“发生火灾”），自动播放引导视频+语音，提示“请立即拨打110/122/119紧急电话，本APP仅提供咨询参考，不替代真实警务”。

- 形象合规：数字人形象、APP图标、界面设计严格遵循公安形象规范，不使用违规警徽、警标，不出现不符合警用规范的文字、画面。

- 标注说明：APP首页、视频播放界面显著位置标注“AI数字人警务助手，仅供咨询参考，不具备执法效力”，避免用户误解。

# 五、分阶段实施规划（优化后，简化流程、降低难度）

总周期：3-4天（比原流程缩短1-2天），核心简化“实时数字人生成”环节，重点推进本地视频制作和扣子工作流简化配置。

## 阶段1：扣子空间搭建（1-2天，核心简化）

- 1.1 搭建警用专业知识库：上传公安官方权威资料（户籍、交通、反诈、法规等），确保回答专业、合规，无需配置数字人相关插件。

- 1.2 简化AI工作流：创建核心工作流，无需添加“数字人实时生成”节点，流程为：
用户语音→ASR转文字→知识库检索→大模型应答→TTS转语音→输出语音信号（同步给安卓端，用于匹配本地视频）。

- 1.3 配置语音功能：设置唤醒词、ASR/TTS参数，调试语音识别、合成准确率，确保警用音色正式、清晰。

- 1.4 生成Web应用/API：发布扣子Web应用（生成链接），或生成API接口（供安卓端调用），无需配置数字人相关接口。

## 阶段2：本地假视频制作（1天，新增核心环节）

- 2.1 确定数字人形象：选择合规的警察数字人形象（虚拟/真人授权），确定着装、表情、动作规范。

- 2.2 制作视频片段：按“基础片段+场景片段”分类制作，符合MP4格式、720P分辨率要求，口型贴合常用应答话术，确保音频与后续TTS语音匹配。

- 2.3 视频测试：测试视频清晰度、音频同步性，确保无杂音、无卡顿，适配安卓端播放。

## 阶段3：安卓APP封装与视频集成（1天）

- 3.1 封装基础APP：采用Web封装方式（最快），填入扣子Web应用链接，设置APP名称、图标（警用风格）。

- 3.2 集成本地视频：将制作好的假视频打包至APP安装包，配置视频加载逻辑、场景匹配逻辑，实现“语音应答+视频同步播放”。

- 3.3 权限配置：申请麦克风、存储权限，优化APP运行速度，确保视频加载≤1秒，无闪退、卡顿。

## 阶段4：功能测试与优化（0.5-1天）

- 4.1 核心功能测试：语音唤醒成功率、语音识别准确率、问答专业性、本地视频匹配准确率、视频与语音同步性。

- 4.2 性能测试：测试不同安卓设备（中低端/高端）的运行流畅度，内存占用、加载速度，优化卡顿问题。

- 4.3 合规测试：检查紧急引导、形象合规、标注说明等功能，确保符合警用规范。

- 4.4 优化调整：根据测试结果，调整语音灵敏度、视频匹配逻辑、APP界面，确保用户体验。

# 六、用户操作流程（优化后，简洁流畅）

1. 安装并打开安卓APP，进入首页，显示警察数字人静态画面（或循环播放通用片段）。

2. 用户说出唤醒词（如“小警”），APP快速唤醒，自动播放本地“唤醒应答视频”，同时语音输出“我在，请提问”。

3. 用户语音提问（如“身份证丢了怎么补办？”），APP实时将语音转为文字，显示在界面下方。

4. 扣子空间大模型检索知识库，生成专业应答文字，同时输出场景标签，APP匹配对应本地视频片段。

5. 同步播放本地视频和语音，视频口型、动作与语音完全同步，用户可观看视频、聆听应答。

6. 问答结束后，视频自动停止，回到数字人静态画面，等待下一次唤醒；用户可随时打断视频，继续提问。

7. 若用户提问紧急警情，APP自动播放引导视频+语音，提示拨打紧急电话。

# 七、关键约束与注意事项

## 7.1 性能约束

- 安卓设备要求：内存≥2GB，安卓版本≥8.0，存储空间≥200MB（用于安装APP和视频缓存）。

- 运行性能：APP启动时间≤3秒，视频加载时间≤1秒，无闪退、卡顿，语音识别延迟≤1秒。

- 内存占用：运行时内存占用≤500MB，避免影响安卓设备其他应用运行。

## 7.2 合规约束

- 形象合规：数字人形象、警徽、警标、警服等元素，必须符合《中华人民共和国人民警察法》及公安相关规范，禁止违规使用。

- 回答合规：所有应答内容必须基于公安官方政策、法律法规，不编造信息、不提供非官方建议，不处理紧急警情。

- 隐私保护：不收集、不存储用户语音、位置、身份证等隐私信息，APP权限仅用于核心功能。

## 7.3 本地视频注意事项

- 视频更新：后续新增警务场景，可通过APP版本更新，补充新增本地视频片段，无需重新开发核心功能。

- 口型同步：视频制作时，需严格贴合常用应答话术的语速、语气，确保与TTS语音同步，避免错位。

- 视频体积：单个视频片段体积控制在10MB以内，总视频体积控制在80MB以内，避免APP安装包过大。
